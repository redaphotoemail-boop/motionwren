# Standing rules (read first, every session)

1. **Never remove, hide, gate or rewrite a working feature that is not part of the request.** Change only what was agreed. If a request seems to conflict with something existing, keep it and ask.
2. Read `PROTECTED_FEATURES.md` and run `npm run test:protected` before committing any change under `app/studio/` or `app/admin/`.
3. Never modify the baked prompts. Ask before every merge to main. No destructive git. No secrets.
